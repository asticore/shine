Shine CSS reference

Every class and data attribute in Shine, with live examples. This page is generated from the CSS source, so it always matches the code. Try the playground.

Getting started

Shine is a pure-CSS utility framework. Add one stylesheet and use class names. There is no JavaScript to load and no build step to run.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">

How classes combine

A component class gives you the base look. Modifier classes change it. Tone classes recolor it. Utilities adjust it locally.

<button class="btn btn-outline tone-danger mt-4 md:mt-0">Delete</button>

Knobs first, utilities second

Start by setting a few master knobs on <html>: theme, corner radius, shadow, density and brand colors. The whole site follows. Reach for utility classes only when one element needs to differ. Your own CSS always wins over Shine, so you never need !important.

<html data-theme="auto" data-radius="3" data-shadow="2" style="--sh-primary:#0ea5e9">

Master knobs

Knobs are data attributes and CSS variables. Set them on <html> for the whole site, or on any element to restyle just that subtree.

Overlays: modal, offcanvas, dropdown, tooltip

No JavaScript. Modals use <dialog> with command / commandfor (Invoker Commands). Offcanvas uses the Popover API. Dropdowns use <details>. Tooltips use a data attribute.

Toast

Saved. Your changes are live.
A static toast is just a card notice.
<button class="btn" popovertarget="demo-toast">Show toast</button>
<div id="demo-toast" popover="manual" class="toast tone-success" role="status">
  <strong>Saved.</strong> Your changes are live.
  <button class="btn-close" popovertarget="demo-toast" popovertargetaction="hide" aria-label="Dismiss"></button>
</div>
<div class="toast tone-info">A static toast is just a card notice.</div>

Showing needs a trigger: a popovertarget button works with no JS, but opening one automatically (after a save, say) needs el.showPopover(); popover="manual" does not auto-dismiss, so call hidePopover() after a timeout if you want that.

Modal title

Variants and cascade

Responsive prefixes

Mobile first. An unprefixed class applies everywhere; a prefixed class applies at that width and up. Only layout-critical utilities have them (see the Variants column above).

Hover and focus

hover: applies on pointer hover. focus: applies on :focus-visible, so it only shows for keyboard focus. They exist on colors, opacity, shadow and underline.

<a class="text-muted hover:text-primary focus:underline" href="#">Link</a>

There is no dark: variant. Themes switch dark mode through tokens, so the same classes work in both.

Cascade layers

Shine is built with CSS @layer. Utilities beat components, components beat base, and your own unlayered CSS beats everything, with no specificity fights.

@layer shine.tokens, shine.reset, shine.base, shine.components, shine.utilities;

Opacity modifiers

Opacity is a second class, not a slash. Add bg-o-50 next to a background color (also text-o-* and border-o-*).

<div class="bg-primary bg-o-50 p-4">Half-transparent primary</div>

Differences from Tailwind

  • Semantic colors. bg-primary, text-danger, bg-primary-soft, text-muted, bg-surface, plus one gray-50 to gray-950 scale. Add brand colors as tokens.
  • Opacity modifier classes (bg-o-50) instead of bg-primary/50.
  • Radius scales with data-radius: rounded-lg is 1.5 times the global radius.
  • Spacing scales with --sh-space (default .25rem): p-4 is 4 units.
  • No arbitrary values like w-[13px]; use inline styles or your own CSS.
  • No dark: variant. Use data-theme.
  • Fewer variants. Only responsive on layout, hover and focus on colors and effects.
