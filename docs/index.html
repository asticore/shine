Shine CSS framework

Ultra-light, pure-CSS framework: utility classes, ready-made components and master design knobs.

The whole framework is one stylesheet of 15.7 KB gzipped (measured with node build.js). Modals, drawers, dropdowns, tooltips and accordions run on native HTML, so there is nothing to compile and no script to load.

What is Shine?

A single prebuilt stylesheet with utilities, components and design knobs.

Does it need JavaScript?

No. Native details, dialog and popover elements do the work.

Can I override it?

Yes. Shine lives in cascade layers, so your CSS always wins.

Why Shine

Small enough to forget about

One stylesheet, a few knobs, and your own CSS always wins.

  • 01

    Master knobs

    Brand color, theme, corner level, shadow depth and density set once on <html>. Everything follows.

  • 02

    Utilities without a compiler

    Write flex, p-4 and md:grid-cols-3 straight in your HTML. Nothing to install.

  • 03

    Components without JavaScript

    Modals, drawers, dropdowns, tooltips, toasts, accordions: native dialog, popover and details.

  • 04

    15.7 KB gzipped

    Smaller than most hero images. Trim it further with node build.js --only=....

  • 05

    Accessible by default

    Semantic HTML targets, visible focus rings, a skip link, reduced-motion and print styles.

  • 06

    No specificity fights

    Built on CSS cascade layers: your unlayered CSS beats Shine without !important.
